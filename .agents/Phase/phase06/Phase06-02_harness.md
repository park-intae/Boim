# Phase 06-02: 전역 UI/UX 폴리싱 및 모바일 트랜지션 고도화

## 🎯 목표
기능과 레이아웃 배치가 완료된 화면들에 대해 생동감 있는 **마이크로 인터랙션**과 **부드러운 화면 전환(애니메이션)**을 적용하여 앱의 완성도(Quality)와 사용자 경험(UX)을 대폭 끌어올립니다.

## ✅ 체크리스트

### 1. 모바일 바텀 시트 (RightPanel) 애니메이션 폴리싱
- [x] 단순 `hidden/flex` 토글로 딱딱하게 끊기던 모바일 패널을, 아래에서 위로 부드럽게 올라오는 **Slide-Up 애니메이션**으로 개선합니다 (`translate-y` 활용).
- [x] 패널이 열렸을 때 백그라운드와 시각적으로 분리되도록 그림자(`shadow`)와 깊이감(Depth)을 최적화합니다.

### 2. 마이크로 인터랙션 (Tactile Feedback) 추가
- [x] 캘린더 날짜 셀, 요약 카드, 하단 액션 버튼 등 클릭 가능한 주요 요소에 누를 때 약간 눌리는 듯한 피드백(`active:scale-95` 등)을 추가하여 조작감을 향상시킵니다.
- [x] 호버(`hover:`) 시의 색상 전환이나 그림자 효과가 너무 튀지 않고 자연스럽게 스며들도록 `transition-all duration-200` 등을 일관성 있게 적용합니다.

### 3. 타이포그래피 및 여백 세밀 조정 (Pixel Perfect)
- [x] 모바일과 데스크탑 각각에서 폰트 사이즈와 자간(Tracking), 줄간격(Leading)이 완벽한 가독성을 제공하는지 재검토합니다.
- [x] 정보의 중요도에 따라 색상 대비(`text-gray-900` vs `text-gray-500`)와 굵기(Hierarchy)를 세밀하게 다듬습니다.

### 4. 프로필 창 옆 알람 버튼 작동
- [x] 버튼 클릭 시 팝오버 형태로 알림 표시
- [x] 신규 알림이 있을 경우에만 도트 표시

### 5. 종합 검수
- [x] 도입된 애니메이션이 리플로우(Reflow)를 유발하지 않고 `transform`과 `opacity` 위주로 가볍게 설계되었는지 점검합니다.
- [x] iOS 및 Android 모바일 브라우저 환경을 가정하여 애니메이션이 끊김(Stuttering) 없이 60fps로 동작하는지 확인합니다.

### 6. 헤더 메뉴 정리 및 타이포그래피
- [x] PC 네비게이션 및 모바일 햄버거 메뉴를 제거하고, 알림(팝오버), 프로필만 남깁니다.
- [x] 헤더의 '보험 일정' 타이틀 문구를 헤더 정중앙으로 이동시켜 안정감을 줍니다.

### 7. 대시보드 요약 카드 세부 폴리싱
- [x] 아이콘 크기 축소
- [x] 전체 글씨 크기 축소 (타이틀 및 금액)
- [x] 아바타(아이콘)와 글씨를 세로(flex-col)로 배치하여 글씨가 아이콘 하단에 오도록 변경
