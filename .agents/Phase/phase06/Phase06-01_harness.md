# Phase 06-01: 전역 레이아웃(AppLayout, Sidebar, RightPanel) 반응형 상세 포지셔닝

## 🎯 목표
기존에 데스크탑 환경(고정 너비)에 맞춰 설계되었던 `AppLayout`, `Sidebar`, `RightPanel`의 전역 레이아웃을 모바일 및 태블릿 화면에서도 직관적이고 사용하기 편하도록 반응형 위치(포지셔닝)를 명확히 재정의합니다.

## ✅ 체크리스트

### 1. Sidebar (왼쪽 메뉴바) 반응형 설계
- [ ] 데스크탑(`lg` 이상)에서는 기존처럼 좌측 고정 패널(`w-[260px]`)로 유지
- [ ] 모바일/태블릿(`lg` 미만)에서는 하단 고정 네비게이션(Bottom Nav) 또는 상단 헤더(Hamburger Menu) 형태로 변환하여 화면 공간 확보
- [ ] 로고 및 요약 패널 등 모바일 뷰에서 불필요하게 공간을 차지하는 요소 숨김 또는 축소 처리

### 2. AppLayout (메인 컨테이너) 구조 변경
- [ ] 모바일/태블릿 환경을 위해 좌우 분할(`flex-row`)에서 상하 분할(`flex-col`) 구조로 자연스러운 전환 확보
- [ ] 하단 네비게이션 적용 시, 메인 콘텐츠가 하단 바에 가려지지 않도록 하단 여백(`pb-`) 확보
- [ ] 콘텐츠 중앙 정렬 및 좌우 여백(`px`)을 기기 크기에 맞춰 가변(`px-4 md:px-8 lg:px-10`)으로 적용

### 3. RightPanel (우측 패널) 포지셔닝 최적화 (Bottom Sheet 패턴)
- [ ] 데스크탑(`lg` 이상)에서는 기존 우측 고정(`w-[380px]`) 레이아웃 유지
- [ ] 모바일 환경에서는 화면 하단에서 위로 올라오는 **바텀 시트(Bottom Sheet) / 아코디언 형태**의 오프캔버스로 작동하도록 레이아웃 분리
- [ ] 모바일 바텀 시트 상태일 때, 패널 우측 상단에 닫기(`X`) 버튼을 배치하여 누르면 부드럽게 밑으로 접히며(사라지며) 메인 캘린더 화면을 온전히 볼 수 있도록 상태(State) 관리 추가
- [ ] 설정(Settings) 등 내부 컴포넌트들이 바텀 시트 안에서도 스크롤 가능하며 꽉 차게 렌더링되도록 디자인 디테일 최적화

### 4. 종합 검수
- [ ] 데스크탑 환경에서 기존 레이아웃이 깨지지 않는지 크로스 브라우징 확인
- [ ] 모바일 환경(320px~480px)에서 가로 스크롤이 발생하지 않고 모든 패널이 올바른 위치에 렌더링되는지 확인
