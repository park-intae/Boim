# Phase 06-01: 전역 레이아웃(AppLayout, Sidebar, RightPanel) 반응형 상세 포지셔닝

## 🎯 목표
기존에 데스크탑 환경(고정 너비)에 맞춰 설계되었던 `AppLayout`, `Sidebar`, `RightPanel`의 전역 레이아웃을 모바일 및 태블릿 화면에서도 직관적이고 사용하기 편하도록 반응형 위치(포지셔닝)를 명확히 재정의합니다.

## ✅ 체크리스트

### 1. Sidebar (왼쪽 메뉴바) 반응형 설계
- [x] 데스크탑(`lg` 이상)에서는 기존처럼 좌측 고정 패널(`w-[260px]`)로 유지
- [x] 모바일/태블릿(`lg` 미만)에서는 우측 햄버거 메뉴에서 열리는 아코디언 메뉴로 수정할 것
- [x] 로고 및 요약 패널 등 모바일 뷰에서 불필요하게 공간을 차지하는 요소 숨김 또는 축소 처리

### 2. AppLayout (메인 컨테이너) 구조 변경
- [x] 모바일/태블릿 환경을 위해 좌우 분할(`flex-row`)에서 상하 분할(`flex-col`) 구조로 자연스러운 전환 확보
- [x] 하단 네비게이션 적용 시, 메인 콘텐츠가 하단 바에 가려지지 않도록 하단 여백(`pb-`) 확보
- [x] 콘텐츠 중앙 정렬 및 좌우 여백(`px`)을 기기 크기에 맞춰 가변(`px-4 md:px-8 lg:px-10`)으로 적용

### 3. RightPanel (우측 패널) 포지셔닝 최적화
- [x] 데스크탑(`lg` 이상)에서는 기존 우측 고정(`w-[380px]`) 레이아웃 유지
- [x] 모바일 화면에서는 메인 콘텐츠 하단에 아코디언 메뉴 형태로 존재하며 작동 버튼 클릭시 열리고 우측 상단의 x 버튼으로 닫는 동작으로 제작할 것
- [x] 우측 패널 내부의 요소(보험 일정, 알림, 설정 폼)가 모바일 전체 너비(`w-full`)에 맞게 패딩과 아이콘 크기가 조절되도록 세부 조정

### 4. 추가 UI 고도화 및 반응형 디테일 (사용자 피드백 반영)
- [x] **대시보드 요약 카드 (HomePage)**: 모바일 환경에서 4개의 카드가 찌그러지지 않도록 2x2 그리드 레이아웃(`grid-cols-2`)으로 변경하고 폰트/아이콘 크기 반응형 조절.
- [x] **캘린더 헤더 (MainCalendar)**: 캘린더 상단의 월별 네비게이션 버튼 영역이 모바일 화면을 벗어나지 않도록, 날짜 타이틀과 네비게이션을 2줄(`flex-col`)로 래핑하여 꽉 찬 레이아웃 구성.
- [x] **캘린더 자동 스크롤 (MainCalendar)**: 캘린더 렌더링 시, 선택된 날짜(또는 오늘)가 포함된 주(Week)가 스크롤 영역의 정중앙에 위치하도록 자동 스크롤(`scrollIntoView`) 기능 구현.
- [x] **모바일 바텀 시트 자동 팝업 (useAppStore, RightPanel)**: 우측 패널 열림 상태를 전역 상태(`isMobilePanelOpen`)로 관리하여, 햄버거 메뉴 및 추가 버튼 조작 시 패널이 화면 아래에서 위로 자동 전개되도록 UX 개선.

### 5. 종합 검수
- [x] 데스크탑 환경에서 기존 레이아웃이 깨지지 않는지 크로스 브라우징 확인
- [x] 모바일 환경(320px~480px)에서 가로 스크롤이 발생하지 않고 모든 패널이 올바른 위치에 렌더링되는지 확인
