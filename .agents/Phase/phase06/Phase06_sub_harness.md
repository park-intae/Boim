# Phase 06 하위 작업 통합 하네스 (Phase 06 Sub-Harness)

본 문서는 Phase 06(설정 페이지 반응형 및 UI/UX 폴리싱) 과정에서 진행된 세부 하위 작업(Phase 06-01: 전역 레이아웃 반응형 상세 포지셔닝, Phase 06-02: 전역 UI/UX 폴리싱 및 모바일 트랜지션 고도화)의 실행 내역과 체크리스트를 하나로 통합 정리한 문서입니다.

---

## 📋 Phase 06-01: 전역 레이아웃(AppLayout, Sidebar, RightPanel) 반응형 상세 포지셔닝

> **목표:** 기존 데스크탑 환경에 맞춰졌던 `AppLayout`, `Sidebar`, `RightPanel`의 전역 레이아웃을 모바일 및 태블릿 화면에서도 직관적이고 사용하기 편하도록 반응형 위치를 명확히 재정의합니다.

### 1. Sidebar (왼쪽 메뉴바) 반응형 설계
- [x] 데스크탑(`lg` 이상)에서는 기존처럼 좌측 고정 패널(`w-[260px]`)로 유지
- [x] 모바일/태블릿(`lg` 미만)에서는 우측 햄버거 메뉴에서 열리는 아코디언 메뉴로 수정
- [x] 로고 및 요약 패널 등 모바일 뷰에서 불필요하게 공간을 차지하는 요소 숨김 또는 축소 처리

### 2. AppLayout (메인 컨테이너) 구조 변경
- [x] 모바일/태블릿 환경을 위해 좌우 분할(`flex-row`)에서 상하 분할(`flex-col`) 구조로 자연스러운 전환 확보
- [x] 하단 네비게이션 적용 시, 메인 콘텐츠가 하단 바에 가려지지 않도록 하단 여백(`pb-`) 확보
- [x] 콘텐츠 중앙 정렬 및 좌우 여백(`px`)을 기기 크기에 맞춰 가변(`px-4 md:px-8 lg:px-10`)으로 적용

### 3. RightPanel (우측 패널) 포지셔닝 최적화
- [x] 데스크탑(`lg` 이상)에서는 기존 우측 고정(`w-[380px]`) 레이아웃 유지
- [x] 모바일 화면에서는 메인 콘텐츠 하단에 아코디언 메뉴 형태로 존재하며 작동 버튼 클릭 시 열리고 우측 상단의 x 버튼으로 닫는 동작으로 제작
- [x] 우측 패널 내부 요소(보험 일정, 알림, 설정 폼)가 모바일 전체 너비(`w-full`)에 맞게 패딩과 아이콘 크기 조절

### 4. 추가 UI 고도화 및 반응형 디테일
- [x] **대시보드 요약 카드 (HomePage)**: 모바일 환경에서 4개의 카드가 찌그러지지 않도록 2x2 그리드 레이아웃(`grid-cols-2`)으로 변경하고 폰트/아이콘 크기 반응형 조절
- [x] **캘린더 헤더 (MainCalendar)**: 캘린더 상단 월별 네비게이션 버튼 영역이 모바일 화면을 벗어나지 않도록 날짜 타이틀과 네비게이션을 2줄(`flex-col`)로 래핑하여 꽉 찬 레이아웃 구성
- [x] **캘린더 자동 스크롤 (MainCalendar)**: 캘린더 렌더링 시, 선택된 날짜(또는 오늘)가 포함된 주(Week)가 스크롤 영역의 정중앙에 위치하도록 자동 스크롤(`scrollIntoView`) 구현
- [x] **모바일 바텀 시트 자동 팝업 (useAppStore, RightPanel)**: 우측 패널 열림 상태를 전역 상태(`isMobilePanelOpen`)로 관리하여, 추가 버튼 조작 시 패널이 화면 아래에서 위로 자동 전개되도록 UX 개선

### 5. 종합 검수
- [x] 데스크탑 환경에서 기존 레이아웃이 깨지지 않는지 크로스 브라우징 확인
- [x] 모바일 환경(320px~480px)에서 가로 스크롤이 발생하지 않고 모든 패널이 올바른 위치에 렌더링되는지 확인

## 📋 Phase 06-02: 전역 UI/UX 폴리싱 및 모바일 트랜지션 고도화

> **목표:** 기능과 레이아웃 배치가 완료된 화면들에 대해 생동감 있는 마이크로 인터랙션과 부드러운 화면 전환(애니메이션)을 적용하여 앱의 완성도와 사용자 경험을 대폭 끌어올립니다.

### 1. 모바일 바텀 시트 (RightPanel) 애니메이션 폴리싱
- [x] 단순 `hidden/flex` 토글 대신 아래에서 위로 부드럽게 올라오는 **Slide-Up 애니메이션** 개선 (`translate-y` 활용)
- [x] 패널이 열렸을 때 백그라운드와 시각적으로 분리되도록 그림자(`shadow`)와 깊이감(Depth) 최적화

### 2. 마이크로 인터랙션 (Tactile Feedback) 추가
- [x] 캘린더 날짜 셀, 요약 카드, 하단 액션 버튼 등 클릭 가능한 주요 요소에 누를 때 눌리는 듯한 피드백(`active:scale-95` 등) 추가
- [x] 호버(`hover:`) 시의 색상 전환이나 그림자 효과가 자연스럽게 스며들도록 `transition-all duration-200` 적용

### 3. 타이포그래피 및 여백 세밀 조정
- [x] 모바일과 데스크탑 각각에서 폰트 사이즈와 자간(Tracking), 줄간격(Leading) 가독성 재검토
- [x] 정보의 중요도에 따라 색상 대비(`text-gray-900` vs `text-gray-500`)와 굵기(Hierarchy) 다듬기

### 4. 프로필 창 옆 알림 버튼 작동
- [x] 버튼 클릭 시 팝오버 형태로 알림 표시
- [x] 신규 알림이 있을 경우에만 도트 뱃지 표시

### 5. 헤더 메뉴 정리 및 타이포그래피
- [x] PC 네비게이션 및 모바일 햄버거 메뉴를 제거하고, 알림(팝오버), 프로필만 유지
- [x] 헤더의 '보험 일정' 타이틀 문구를 헤더 정중앙으로 이동시켜 안정감 부여

### 6. 대시보드 요약 카드 세부 폴리싱
- [x] 아이콘 크기 및 전체 글씨 크기 축소
- [x] 아바타와 글씨를 세로(flex-col)로 배치하여 글씨가 아이콘 하단에 오도록 변경
