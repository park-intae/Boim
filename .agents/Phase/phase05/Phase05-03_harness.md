# Phase 05-03: 알림 (Notifications) 기능 구현

> **목표:** 좌측 사이드바의 '알림' 메뉴 클릭 시, 사용자에게 도달한 이벤트(보험료 납입일 도래, 갱신 알림 등) 목록을 확인할 수 있는 알림 패널 뷰를 구현합니다. 단위 테스트를 통해 UI와 상태 관리 로직을 검증합니다.

## ✅ 체크리스트

### 1. 알림 모드 상태 관리 및 사이드바 연동
- [x] `useAppStore`의 `panelMode` 타입에 `'notifications'` 모드 추가
- [x] 좌측 `Sidebar` 컴포넌트의 '알림' 메뉴 클릭 시 `setPanelMode('notifications')` 호출 로직 구현 및 활성화 스타일 적용
- [x] 🧪 **[Test]** `useAppStore.test.ts`에 `'notifications'` 모드 전환 검증 테스트 추가
- [x] 🧪 **[Test]** `Sidebar.test.tsx`에서 '알림' 클릭 동작 검증 테스트 추가

### 2. 알림 리스트 컴포넌트(`NotificationList`) 뼈대 및 UI 구현
- [x] `panelMode === 'notifications'`일 때 메인 또는 우측 패널에 렌더링될 `<NotificationList />` 컴포넌트 생성
- [x] 알림 아이템(알림 타입, 제목, 시간, 읽음 여부)을 렌더링하기 위한 더미 데이터 또는 임시 상태 구성
- [x] 개별 알림 아이템의 UI (읽지 않은 알림 강조, 아이콘 표시 등) 스타일링 적용
- [x] 🧪 **[Test]** `<NotificationList />`가 알림 목록을 올바르게 렌더링하는지 단위 테스트 작성

### 3. 알림 상호작용 및 상태 처리
- [x] 알림 항목 클릭 시 해당 알림을 '읽음' 상태로 변경하는 로직(혹은 클릭 효과) 구현
- [x] 수신된 알림이 없을 경우(Empty State)를 위한 안내 문구 및 UI 구현
- [x] 🧪 **[Test]** 데이터가 비어있을 때 Empty State 컴포넌트가 올바르게 렌더링되는지 검증
- [x] 🧪 **[Test]** 알림 클릭 이벤트 동작 검증

### 4. 엣지 케이스 및 마무리
