# Phase 05-06: 설정 페이지 반응형 및 UI/UX 폴리싱

## 🎯 목표
앞서 구현한 Phase 05-05 설정 페이지 및 하위 뷰(내 정보, 비밀번호, 알림 시간, 로그인 기록, 약관 모달 등)가 다양한 디바이스(모바일, 태블릿, 데스크탑)에서 깨지지 않고 유려하게 보이도록 반응형 설계를 적용하고 UI 디테일을 폴리싱합니다.

## ✅ 체크리스트

### 1. 공통 패널 레이아웃 반응형 개선
- [ ] `SettingsPanel` 및 모든 하위 뷰의 여백(Padding)을 모바일 친화적으로 가변 적용 (`px-4 sm:px-6` 등)
- [ ] 패널이 너무 넓어지는 것을 방지하기 위한 최대 너비(`max-w-2xl mx-auto w-full` 등) 제한 적용

### 2. 컴포넌트 내부 반응형 폴리싱
- [ ] **ProfileSettings**: 입력 폼과 프로필 이미지 섹션이 모바일 환경에서 좁아지지 않도록 간격 및 너비 조정
- [ ] **PasswordSettings**: 비밀번호 입력창의 너비 및 토글 아이콘 위치가 모든 해상도에서 유지되도록 조정
- [ ] **NotificationTimeSettings**: 시간 입력 폼(`input[type="time"]`) 영역의 너비 가변성 확보
- [ ] **LoginHistorySettings**: 기기 정보, IP, 시간 텍스트가 모바일에서 줄바꿈이 자연스럽게 일어나도록 레이아웃(`flex-wrap`, `min-w-0`, `truncate` 등) 최적화
- [ ] **PolicyViewer**: 약관 텍스트 모달이 모바일 화면 크기에 맞게 내부 스크롤이 자연스럽게 발생하도록 여백 조정

### 3. 검수
- [ ] 전체 설정 패널이 모바일(320px~480px) 환경에서 스크롤 및 요소 겹침 현상이 없는지 확인
