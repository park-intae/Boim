# Phase 05-05: 설정(Settings) 기능 제작

## 🎯 목표
사용자의 계정 정보, 알림 설정 및 세션/데이터 관리를 위한 설정 페이지 UI와 백엔드 API를 구현합니다. (디자인 시안 `wireframe.png` 완벽 반영)

## ✅ 체크리스트

### 1. UI/UX 구조 잡기 (공통)
- [x] 설정 모달/패널 기본 레이아웃 구성 (Tailwind CSS 활용)
- [x] 디자인 시안의 4가지 주요 섹션(계정 설정, 알림 설정, 데이터 관리, 기타) 틀 잡기

### 2. 계정 설정
- [x] **내 정보 관리**: 사용자 프로필 및 기본 정보 조회/수정 UI 및 API 연동
- [x] **비밀번호 변경**: 비밀번호 변경 폼 및 검증 로직 구현
- [ ] **로그인 기록**: 접속 기기/세션 목록 조회 및 관리 (여유 시 진행)

### 3. 알림 설정
- [x] **푸시 알림**: 웹 푸시(FCM 등) 수신 동의 토글 UI 및 API
- [x] **이메일 알림**: 이메일 수신 동의 토글 UI 및 API
- [x] **카카오톡 알림**: 카카오톡 수신 동의 토글 UI 및 API
- [x] **알림 시간 설정**: 방해 금지 시간 등 알림 발송 시간대 설정 UI 및 API

### 4. 데이터 관리 및 보안
- [x] **데이터 내보내기**: 사용자의 보험/일정 데이터 Export 기능
- [x] **데이터 가져오기**: 외부 데이터 Import 기능
- [x] **계정 탈퇴**: 본인 확인 절차 및 소프트 딜리트 처리 (빨간색 텍스트 강조)
- [x] **로그아웃**: 시안에는 명시되지 않았으나 계정 보안을 위한 기본 기능 구현

### 5. 기타
- [ ] **이용약관**: 약관 페이지 연결 또는 모달 뷰어 제공

---
**주의사항**: 모든 API 요청은 TanStack Query를 사용하고, 백엔드는 JWT와 Row-level 권한 통제를 기반으로 본인의 설정만 변경할 수 있도록 합니다.
