- [ ] 로고 영역 구성
  - [ ] 텍스트 타이포그래피(Boim) 폰트 패밀리, 크기, 굵기 등 시안 맞춤 적용

  - [ ] 메뉴 항목별 정확한 아이콘(Lucide React) 매칭 및 사이즈 설정

  - [ ] 메뉴 호버(Hover) 시 트랜지션(Transition) 애니메이션 및 피드백 시각화 적용
  - [ ] 네비게이션 항목들 사이의 수직 간격(gap/margin) 정밀 조정
- [ ] 하단 '내 보험 요약' 패널 구성
  - [ ] 사이드바 최하단 구역에 고정 또는 Flexbox 기반 하단 배치 적용
  - [ ] 요약 정보 카드/박스 형태 UI 백그라운드 및 테두리(Border/Shadow) 스타일링
  - [ ] 정보 요소(총 납입액, 유지 건수 등) 텍스트 계층 구조(Hierarchy) 확립
