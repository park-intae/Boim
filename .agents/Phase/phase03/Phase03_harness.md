# Phase 03: 디자인 시안 적용 및 UI/UX 고도화

## 🎯 목표
- 첨부된 디자인 시안(목업)을 바탕으로 프론트엔드 UI를 세밀하게 다듬습니다.
- 대시보드 요약 정보 및 캘린더 화면을 고품질 컴포넌트로 구현합니다.
- 동적인 상호작용(호버, 마이크로 애니메이션)을 추가하여 애플리케이션의 완성도를 높입니다.

## ✅ 체크리스트

### 1. 전역 디자인 시스템 및 Tailwind 설정 고도화
- [ ] 🎨 **색상 및 타이포그래피 보완:** 시안에 맞춘 커스텀 색상(브랜드 컬러, 배경, 텍스트) 및 폰트 세팅 (`index.css`, `tailwind.config.ts`)
- [ ] 🧩 **공통 컴포넌트 추출:** 뱃지(Badge), 카드(Card), 버튼(Button) 등 자주 쓰이는 UI 요소를 재사용 가능한 컴포넌트로 분리

### 2. 가입 현황 화면(Insurance) UI 폴리싱
- [ ] ✨ **리스트 카드 디자인 개선:** 시안에 맞춰 기존 그리드 뷰를 다듬고, 카드 내부 텍스트 위계 및 여백 최적화
- [ ] 📝 **등록 폼 모달(또는 페이지) 구현:** `react-hook-form` 및 `zod`를 활용한 보험 등록 입력 폼 UI 및 유효성 검사 적용

### 3. 대시보드(Home) 메인 화면 구현
- [ ] 📊 **요약 카드 구현:** 총 납입액, 보장 내역 등 핵심 지표를 보여주는 요약(Summary) 위젯 레이아웃 구성
- [ ] 📈 **차트 연동 (선택):** Chart.js 또는 Recharts를 활용한 지표 시각화 (더미 데이터 혹은 실제 데이터 연동)

### 4. 테스트 및 마무리
- [ ] 🧪 신규/수정된 UI 컴포넌트에 대한 렌더링 테스트(RTL) 보완 및 업데이트
- [ ] 🌿 커밋 완료
