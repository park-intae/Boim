# Phase 03: Frontend Layout & UI Detailing (SPA Restructure)

> **목표:** `docs/design/wireframe.png`의 시각적 형태를 완벽하게 반영하는 단일 페이지 애플리케이션(SPA) 레이아웃 뼈대부터 세부 컴포넌트까지 사용자 지시에 따라 정밀하게 구축합니다.

## ✅ 체크리스트

### 1. SPA 글로벌 레이아웃 구축 (완료)
- [x] 화면 전체 영역 4분할 뼈대(좌측 사이드바, 상단 헤더, 중앙 메인, 우측 패널) 구성 완료
- [x] Placeholder를 통한 컴포넌트 구역 확보

### 2. 헤더(Header) 디테일링 (완료)
- [x] 위, 아래 여백 정밀 조정으로 헤더 영역 비중 대폭 축소 (h-60px 적용)
- [x] 알림 버튼 왼쪽에 다크/라이트 버튼 구현 및 호버 적용
- [x] 다크/라이트 아이콘 및 알림 아이콘 그룹과 프로필 간의 여백(Margin) 확보 및 시각적 구분선 추가
- [x] 이용자 부분은 현재 영역만 표시 (추후 로그인 기능 구현 예정)
- [x] 우측 사용자 프로필 디자인 확정 (아바타 링과 그림자를 통해 이미지 영역을 확실하게 돋보이도록 강조)

### 3. 좌측 사이드바 구축 및 고도화
- [x] 로고 영역 구성
  - [x] 텍스트 타이포그래피(Boim) 폰트 패밀리, 크기, 굵기 등 시안 맞춤 적용
  - [x] 로고 컨테이너의 상/하/좌/우 Padding 및 전체 여백 정밀 조정
- [x] 네비게이션 메뉴(GNB) 영역 구성
  - [x] 메뉴 항목별 정확한 아이콘(Lucide React) 매칭 및 사이즈 설정
  - [x] 현재 위치한 메뉴(Active)와 기본 메뉴(Default)의 배경색, 글자색 시각적 분리
  - [x] 메뉴 호버(Hover) 시 트랜지션(Transition) 애니메이션 및 피드백 시각화 적용
  - [x] 네비게이션 항목들 사이의 수직 간격(gap/margin) 정밀 조정
- [x] 하단 '내 보험 요약' 패널 구성
  - [x] 사이드바 최하단 구역에 고정 또는 Flexbox 기반 하단 배치 적용
  - [x] 요약 정보 카드/박스 형태 UI 백그라운드 및 테두리(Border/Shadow) 스타일링
  - [x] 정보 요소(총 납입액, 유지 건수 등) 텍스트 계층 구조(Hierarchy) 확립

### 4. 중앙 메인 컨텐츠 영역 (Center Column)
- [ ] 상단 4개의 요약 카드(Stat Cards) UI 구현
  - [ ] 각 카드별 독립적인 아이콘, 타이틀, 강조된 수치 데이터 UI 레이아웃 설계
  - [ ] 시안에 맞춘 세련된 테두리(Border), 배경색, 라운드 및 은은한 그림자(Shadow) 적용
  - [ ] 4개의 카드가 가로 공간을 균등하게 차지하도록 Grid(또는 Flex) 1열 등분배 배치
  - [ ] 마우스 호버(Hover) 시 카드가 살짝 떠오르거나 색상이 변하는 미세 인터랙션 고도화
- [ ] 대형 메인 캘린더 컴포넌트 구조화 및 렌더링
  - [ ] 캘린더 상단 년/월(Year/Month) 타이포그래피 및 좌우(이전/다음 달) 네비게이션 헤더 구현
  - [ ] 월~일 요일 헤더 영역 시각적 구분 및 주말(토/일) 전용 텍스트 컬러 포인트 적용
  - [ ] 그리드(Grid) 기반의 날짜 셀(Cell) 레이아웃 정밀 배분 (선 간격, 여백 최소화)
  - [ ] 오늘 날짜(Today) 및 현재 선택된 날짜(Selected)에 대한 배경색 및 외곽선 강조 처리
- [ ] 캘린더 내부 일정(Event) 정보 시각화 로직 구현
  - [ ] 일정(납입, 갱신 등)이 존재하는 날짜 하단에 직관적인 뱃지(Dot 또는 라벨) 표시
  - [ ] 일정의 종류 및 상태에 따라 뱃지의 테마 색상 분리 (예: 성공/경고/안내 색상)
  - [ ] 셀 내부 텍스트와 뱃지 사이의 수직 여백 및 정렬 고도화

### 5. 우측 상세 패널 (Right Panel)

- [ ] 패널 하단 네비게이션 버튼 구현
