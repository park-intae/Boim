# Phase 03: 디자인 시안 적용 및 UI/UX 고도화

## 🎯 목표
- 첨부된 디자인 시안(목업)을 바탕으로 프론트엔드 UI를 지정된 순서대로 세밀하게 다듬습니다.
- 사용자 요청에 맞춘 순서로 컴포넌트를 구현하며 고품질의 상호작용과 레이아웃을 완성합니다.

## ✅ 체크리스트

### 1. 전체 레이아웃 (Global Layout)
- [x] 전체적인 화면 분할(Grid/Flex) 및 배경색, 컨테이너 등 베이스 레이아웃 재구성
- [x] Tailwind 전역 설정(Theme, Font, Color 등) 고도화

### 2. 메인 캘린더 (Main Calendar)
- [x] 중앙에 위치할 핵심 컴포넌트인 캘린더 UI 뼈대 및 디자인 시안 적용
- [x] 날짜, 일정(보험 정보 등) 표시를 위한 그리드 렌더링 및 스타일링

### 3. 우측 사이드바 (Right Sidebar)
- [x] 화면 우측에 배치될 부가 정보(요약, 알림, 상세 내역 등) 사이드바 레이아웃 구현
- [x] 시안에 맞춘 세부 컴포넌트(카드, 리스트 등) 조립

### 4. 좌측 사이드바 (Left Sidebar)
- [x] 기존 좌측 네비게이션을 시안에 맞게 아이콘, 텍스트, 호버 이펙트 등 폴리싱
- [x] 전체 디자인 시스템과 톤앤매너 통일

### 5. 테스트 및 마무리
- [x] 변경된 전체 레이아웃 및 각 영역에 대한 렌더링 테스트(RTL) 보완
- [x] 🌿 커밋 완료
