# Phase 07: 테스트 코드 작성 및 커버리지/통과율 확보

> **목표**: 이전 페이즈에서 개발된 기능 및 UI 변경사항에 대한 테스트 코드를 전면 작성하여, 높은 테스트 커버리지(Coverage)와 100% 테스트 통과율(Pass Rate)을 확보합니다. 이를 통해 코드베이스의 안정성을 극대화합니다.

## ✅ 체크리스트

### 1. 테스트 환경 및 기존 테스트 점검
- [ ] 현재 작성되어 있는 기존 테스트 코드들의 통과 여부를 점검합니다. (`pnpm run test`)
- [ ] UI 레이아웃 및 텍스트 변경으로 인해 깨진 기존 테스트 코드를 찾아 최신 스펙에 맞게 수정합니다.

### 2. 신규 UI/UX 기능 테스트 (Header & RightPanel)
- [ ] **Header**: 종소리 알림 버튼 클릭 시 팝오버 토글 동작 및 내부 텍스트('새로운 알림') 렌더링 검증.
- [ ] **RightPanel**: 모바일/데스크탑 환경에서의 패널 노출 여부 및 애니메이션 상태 검증.
- [ ] Zustand 전역 상태(`useAppStore`)의 `panelMode` 변경 로직 테스트 보강.

### 3. 대시보드 요약 카드 (HomePage) 테스트
- [ ] 가입 보험, 납입액, 갱신/만기, 미납 알림 등 4가지 요약 카드의 값이 올바르게 계산 및 렌더링되는지 검증.
- [ ] 축소된 아이콘 및 flex-col 배치에 따른 UI 구조적 무결성 테스트.

### 4. 커버리지 및 통과율 검증
- [ ] 모든 기능 개발/수정 단위에 대한 테스트 코드가 누락 없이 작성되었는지 확인합니다.
- [ ] `pnpm run test` 실행 시, 모든 테스트가 오류 없이 **100% PASS** 하는지 최종 확인합니다.
- [ ] (선택) 커버리지 리포트(`pnpm run test:cov` 등)를 확인하여 주요 로직의 커버리지 지표를 달성합니다.
