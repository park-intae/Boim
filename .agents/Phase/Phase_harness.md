- 단위 작업이 완료될 때마다 반드시 `- [x]` 형태로 체크(완료 처리) 후, **즉각적으로 `git commit`** 하세요.
- 작업이 완료된 Phase는 분산된 하위 하네스 파일들을 `PhaseXX_sub_harness.md` 파일 하나로 통합하고 기존 하위 하네스들은 정리하여, 각 Phase 폴더에 메인 하네스와 하위 하네스 총 2개 파일이 유지되도록 관리하세요.
