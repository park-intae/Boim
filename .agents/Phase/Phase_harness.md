# Phase 폴더 안내

이 폴더는 각 작업에 대한 계획을 체크리스트 형식으로 관리하기 위한 곳입니다.

- **파일 위치 주의**: 작업하는 Phase 번호에 맞는 하위 폴더(예: `phase01`, `phase05`) 내부에 하네스 파일을 생성해야 합니다. (절대 루트 `Phase/` 폴더에 직접 생성하지 마세요)
- 새로운 작업을 시작할 때 해당 하위 폴더에 마크다운 파일(예: `Phase05-05_harness.md`)을 생성하세요.
- 할 일을 순서대로 `- [ ]` 형태로 작성하세요.
- 단위 작업이 완료될 때마다 반드시 `- [x]` 형태로 체크(완료 처리) 후, **즉각적으로 `git commit`** 하세요.
