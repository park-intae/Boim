# Phase 09-01: 프론트-백 연동 수동 통합 테스트 (Manual QA)

## 1. 테스트 목적
- 인증 인프라(일반 로그인, 재인증, PASS 연동 등)와 데이터베이스 연동 과정에서 발생할 수 있는 잠재적인 엣지 케이스 및 오류 식별.
- 백엔드(NestJS) 및 프론트엔드(React) 연동 상의 실제 문제(CORS, 응답 포맷 차이, 토큰 헤더 누락 등) 디버깅 및 수정.

## 2. 수동 테스트 점검 항목
- [ ] 브라우저 상에서 `test@boim.com` 계정을 활용하여 실제 로그인 API 요청이 통과하는지 확인
- [ ] 성공적으로 반환된 AccessToken이 프론트엔드 Zustand 스토어에 잘 저장되는지 확인
- [ ] 이후 호출되는 API(`apiClient`)의 요청 헤더에 `Authorization: Bearer <token>`이 정상적으로 주입되는지 확인
- [ ] 기기 기억(rememberMe) 활성화 시, 브라우저 로컬 스토리지에 토큰이 정상적으로 유지되는지 확인 (새로고침 시 유지 여부)
- [ ] PASS 간이 본인인증 모달 띄우기 및 Mock API 응답 확인
- [ ] 민감 정보 접근 시나리오에서 재인증(ReAuthModal) 모달 띄우고, 실제 비밀번호(`password123`)로 검증 성공하는지 테스트
- [ ] 의도적으로 잘못된 비밀번호를 입력하거나 토큰을 누락했을 때의 에러 핸들링(공통 에러 응답) 동작 검증
