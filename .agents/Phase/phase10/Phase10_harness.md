# Phase 10: 보험 증권 파일 업로드 & 패턴 매칭 데이터 자동 추출 및 폼 자동 입력 (완료)

본 문서는 사용자가 보유한 보험 증권(PDF/이미지/TXT) 파일을 안전하게 업로드하고, OCR(Tesseract.js) 및 정규식/패턴 매칭 파서 엔진을 통해 보험 계약 정보를 즉시 자동 추출하여 폼에 자동 채워주도록 하는 Phase 10의 마스터 하네스입니다.

---

## 🎯 핵심 목표 및 개요
1. **증권 문서 모델 및 안전 업로드 파이프라인 구축 (`Multer`, `Document` 모델)**
   - 증권 파일(PDF, PNG, JPG/JPEG, TXT) 안전 업로드 및 용량/MIME 검증
   - 개인정보 보호를 위한 비식별화 가상 모의 증권 샘플 프리셋 지원
   - Row-level 사용자 소유권 통제 적용
2. **고성능 패턴 매칭 파싱 엔진 구축 (Regex & OCR)**
   - `Tesseract.js` OCR 및 텍스트 파일 판독
   - 정규식/패턴 매칭 기반 비정형 텍스트 구조화 (보험사, 상품명, 카테고리, 월납입액, 만기일 등 JSON 파싱)
   - 토큰 소모 0 및 지연 없는 즉각적 파싱 처리
   - (AI의 역할은 향후 종합 진단 및 분석 리포트 전담으로 재배치)
3. **사용자 경험(UX) 최적화 및 폼 자동 입력(Prefill)**
   - 증권 업로드 드래그 앤 드롭 UI 및 진행 상태(업로드 -> 분석 중 -> 완료) 시각화
   - 원클릭 `[가상 모의 증권 샘플로 원클릭 분석해보기]` 프리셋 테스트 기능 제공
   - 파싱 결과를 우측 패널의 `InsuranceForm`에 자동 채우기(Prefill)하여 원클릭 등록 연동
